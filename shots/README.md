# Project screenshots

Drop screenshots here. The cards pick them up by filename — no code change needed.

| Project | Filenames |
|---|---|
| All Safe — AI-Powered SIEM | `allsafe-1.png`, `allsafe-2.png`, `allsafe-3.png` … |
| GM League — Event & Auction Platform | `gmleague-1.png`, `gmleague-2.png` … |
| Oral Cancer Detection System | `oscan-1.png`, `oscan-2.png` … |

- Numbering starts at 1 and must not skip — the loader stops at the first gap.
- `.png`, `.jpg` and `.webp` all work; keep the extension consistent per project.
- Landscape shots look best; they're cropped to 16:10 in the card.
- Anything under ~1600px wide is plenty. Large files just slow the page down.
